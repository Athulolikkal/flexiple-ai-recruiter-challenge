# Client — Sourcing Refinement Loop

React + TypeScript + Vite + MUI frontend for the Flexiple sourcing refinement loop.

See the [repository root README](../README.md) for the full setup instructions, architecture,
and design decisions — this app only runs together with `server/`.

Quick start (assumes the backend is already running on `http://localhost:4000`):

```bash
npm install
npm run dev
```

Runs on `http://localhost:5173`; `/api/*` is proxied to the backend in dev (see `vite.config.ts`).
